# ProofMesh — two-minute demo script

Target runtime: 1:55–2:10.

## 0:00–0:15 — The problem

“A release decision usually ends in a status meeting because Engineering,
Security, and Support each hold a different piece of the truth. ProofMesh turns
that meeting into a permission-scoped verification protocol.”

**On screen:** Hero. Highlight “Ship only what every team's agent can prove.”

## 0:15–0:30 — The claim

“Here, a release owner asks one precise question: is version 2.4 ready for
production? ProofMesh scopes the decision, the deadline, and the workspace
boundary before contacting anyone.”

**On screen:** Scroll to the case panel and point to the three constraints.

## 0:30–0:55 — Aicoo routing

“When I run the verification, ProofMesh uses Aicoo to route bounded requests to
owner-controlled agents for Engineering, Security, and Support. Each agent
answers only from context its owner permits; the source material is never
centralized here.”

**On screen:** Click **Run the verification**. Let the routing animation finish.

## 0:55–1:20 — Independent evidence

“Engineering verifies 247 CI checks. Security verifies the audit. But Support
finds that the rollback playbook still references a retired queue. ProofMesh
does not smooth over that disagreement. It links each verdict to evidence,
shows confidence, and lowers the proof score.”

**On screen:** Move across the three agent cards, then the 67 proof score.

## 1:20–1:38 — Human accountability

“That contradiction is the only thing sent to a human release owner. Once the
owner confirms the playbook update, ProofMesh seals the decision and the proof
score reaches one hundred.”

**On screen:** Click **Resolve conflict**. Hold on the green sealed state.

## 1:38–1:55 — The ledger

“Every check and the final human decision keeps a receipt in the proof ledger,
so teams can explain not only what shipped, but why.”

**On screen:** Scroll to the proof ledger.

## 1:55–2:08 — Why Aicoo

“ProofMesh depends on Aicoo's agent messaging, scoped context, and persistent
workspace. Agents collaborate, owners stay in control, and trust becomes a
verifiable protocol.”

**On screen:** End on the “Built natively on Aicoo” section and project name.
